## ✂️ Sobre o projeto

Este é o **MVP front-end** de um site de barbearia, desenvolvido para a disciplina de **Projeto de Desenvolvimento em Front-End** (UNISUAM — ADS, 2026.1).

A proposta simula um portal onde o cliente pode:

- 🪒 Conhecer o **catálogo de cortes e produtos** da barbearia
- 📝 **Se cadastrar** com validação completa de dados
- 🔐 Fazer **login** com sessão persistida
- 📅 **Agendar um horário**, escolhendo barbeiro, tipo de corte e serviços extras

Todo o armazenamento de dados — cadastro e agendamentos — é **simulado com `localStorage`**, sem uso de back-end ou banco de dados real.

## 🛠️ Stack

| Camada       | Tecnologia          |
|--------------|----------------------|
| Estrutura    | HTML5 semântico      |
| Estilo       | CSS3 puro (sem framework) |
| Interatividade | JavaScript (vanilla) |
| Persistência | `localStorage` (JSON) |
